# Практика: исследовательская сессия

## Задание

Проведите одну исследовательскую сессию продолжительностью **60 минут** на любом доступном веб-приложении: интернет-магазине, сервисе бронирования или учебной платформе.

### Шаг 1. Сформулируйте чартер (5 минут)

Используйте шаблон:

> Исследовать **<область>**, используя **<приёмы/данные>**, чтобы найти **<какие проблемы>**.

Пример: «Исследовать поиск товаров, используя опечатки, спецсимволы и очень длинные запросы, чтобы найти ошибки обработки ввода».

### Шаг 2. Исследуйте (45 минут)

Ведите заметки по ходу работы:

- что проверили;
- что показалось странным или неудобным;
- какие вопросы возникли к требованиям;
- найденные дефекты (со скриншотами).

### Шаг 3. Подведите итоги (10 минут)

Заполните отчёт о сессии:

| Поле | Содержание |
|------|-----------|
| Чартер | … |
| Длительность | … |
| Что покрыто | … |
| Найденные дефекты | Количество и краткий список |
| Вопросы и риски | … |
| Идеи для следующих сессий | … |

### Шаг 4. Классифицируйте проверки

Из всего, что вы проверили, выберите:

- **3 проверки**, которые стоит оставить ручными, с обоснованием (опирайтесь на урок 3);
- **3 проверки**, которые можно превратить в сценарные тест-кейсы и в будущем автоматизировать.

## Критерии оценки

| Критерий | Баллы |
|----------|-------|
| Чартер конкретный: есть область, приёмы и цель | 2 |
| Заметки сессии отражают ход исследования | 2 |
| Найден и описан хотя бы один дефект или риск | 2 |
| Классификация проверок обоснована | 4 |
| **Итого** | **10** |
