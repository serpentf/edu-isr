# Модуль 1. Введение в тестирование

Что такое тестирование, почему ошибки дешевле ловить рано и какие два подхода к тестированию существуют.

| № | Урок | Тип |
|---|------|-----|
| 1 | Что такое тестирование ПО | Текст |
| 2 | Два подхода: ручное и автоматизированное | Текст |
| 3 | Тест по модулю 1 | Тест |

**Результат модуля:** вы объясните, зачем нужно тестирование, и сможете назвать факторы, от которых зависит выбор между ручным и автоматизированным подходом.
