# Практика 2. Позитивные и негативные проверки

## Задание

Функция `isEven(n)` возвращает `true` для чётных целых чисел и `false` для нечётных.

Напишите тесты с нуля. Помните: одна проверка «4 — чётное» поймает далеко не все ошибки. Функция, которая **всегда** отвечает `true`, этот тест тоже пройдёт.

Подумайте, какие числа стоит проверить:

- чётные и нечётные;
- **ноль** — частый источник ошибок;
- **отрицательные** числа. В JavaScript остаток от деления отрицательного числа отрицательный: `-3 % 2 === -1`.

Это и есть **предугадывание ошибок** (error guessing): проверять места, где программы ломаются чаще всего. Подробнее о технике — в модуле 5.

```js @subject
function isEven(n) {
  return n % 2 === 0;
}
```

```js @starter
test('4 — чётное число', () => {
  expect(isEven(4)).toBe(true);
});

// Добавьте свои тесты ниже
```

```js @solution
test('4 — чётное число', () => {
  expect(isEven(4)).toBe(true);
});

test('7 — нечётное число', () => {
  expect(isEven(7)).toBe(false);
});

test('0 — чётное число', () => {
  expect(isEven(0)).toBe(true);
});

test('-3 — нечётное число', () => {
  expect(isEven(-3)).toBe(false);
});
```

{ "minTests": 3 }

```js @mutant Функция всегда отвечает «чётное»
function isEven(n) {
  return true;
}
```

```js @mutant Функция всегда отвечает «нечётное»
function isEven(n) {
  return false;
}
```

```js @mutant Ноль и отрицательные чётные числа считаются нечётными
function isEven(n) {
  return n > 0 && n % 2 === 0;
}
```

```js @mutant Отрицательные нечётные числа считаются чётными
function isEven(n) {
  return n % 2 !== 1;
}
```
