# Практика 1. Первый автотест

## Как устроены практические задания

В заданиях этого модуля вы пишете **настоящие автотесты на JavaScript** прямо в браузере. Проверка идёт в два шага, как при **мутационном тестировании**:

1. Ваши тесты запускаются на **правильной** реализации функции. Все должны пройти.
2. Те же тесты запускаются на нескольких реализациях **с внесёнными багами**. Каждый баг должен поймать хотя бы один упавший тест.

Так проверяется главное качество автотестов: не то, что они есть, а то, что они **ловят ошибки**. Список багов с подсказками появится после первого запуска.

## Шпаргалка

Синтаксис как в Jest — самом популярном фреймворке для JavaScript:

| Конструкция | Что делает |
|-------------|-----------|
| `test('название', () => { ... })` | Объявляет тест |
| `expect(x).toBe(y)` | `x` строго равен `y` (числа, строки, `true`/`false`) |
| `expect(x).toEqual(y)` | Глубокое сравнение массивов и объектов |
| `expect(x).toBeCloseTo(y)` | Приблизительное равенство дробных чисел |
| `expect(() => f()).toThrow('текст')` | Вызов выбрасывает исключение с этим текстом |
| `expect(x).not.toBe(y)` | Отрицание любой проверки |
| `console.log(x)` | Вывод для отладки — появится под результатами |

## Задание

Функция `sum(a, b)` складывает два числа. В редакторе уже есть тест по схеме **AAA**, но в нём неверное ожидаемое значение.

1. Исправьте ожидаемое значение и запустите тесты.
2. Посмотрите, какие баги тест поймал, а какой — нет.
3. Добавьте второй тест, который поймает оставшийся баг. Подсказка: какие числа вы ещё не пробовали складывать?

```js @subject
function sum(a, b) {
  return a + b;
}
```

```js @starter
test('сумма двух положительных чисел', () => {
  // Arrange
  const a = 2;
  const b = 3;

  // Act
  const result = sum(a, b);

  // Assert
  expect(result).toBe(0); // ← исправьте ожидаемое значение
});
```

```js @solution
test('сумма двух положительных чисел', () => {
  // Arrange
  const a = 2;
  const b = 3;

  // Act
  const result = sum(a, b);

  // Assert
  expect(result).toBe(5);
});

test('сумма с отрицательным числом', () => {
  const result = sum(-4, 1);
  expect(result).toBe(-3);
});
```

```js @mutant Функция умножает вместо сложения

```

```js @mutant Функция теряет знак у отрицательных чисел
function sum(a, b) {
  return Math.abs(a) + Math.abs(b);
}
```
