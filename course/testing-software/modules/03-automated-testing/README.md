# Модуль 3. Автоматизированное тестирование

Как устроена автоматизация, какие бывают её виды, почему тесты выстраивают пирамидой и как выглядит хороший автотест.

**Результат модуля:** вы объясните, почему модульных тестов должно быть больше всего, и напишете на JavaScript автотесты по схеме Arrange–Act–Assert, которые ловят реальные баги.

Практические задания выполняются прямо в браузере. Ваши тесты запускаются на правильной реализации функции и на нескольких реализациях с внесёнными багами. Задание засчитывается, когда тесты проходят на правильном коде и ловят все баги. Сложность растёт от задания к заданию: от исправления одного ожидаемого значения до проверки граничных значений и исключений.
