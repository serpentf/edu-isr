# Модуль 6. Средства тестирования

Обзор инструментов для ручного и автоматизированного тестирования и знакомство с BDD. Инструменты выбираются под технологический стек продукта, бюджет и квалификацию команды. Большинство средств автоматизации из этого модуля бесплатны и имеют открытый исходный код.

| № | Урок | Тип |
|---|------|-----|
| 1 | Инструменты ручного тестирования | Текст |
| 2 | Инструменты автоматизации | Текст |
| 3 | BDD и язык Gherkin | Текст |
| 4 | Практика: подбор стека инструментов | Практика |
| 5 | Тест по модулю 6 | Тест |

**Результат модуля:** вы подберёте набор инструментов под конкретный проект и опишете сценарий на Gherkin.
