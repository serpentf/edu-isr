# Модуль 6. Средства тестирования

Обзор инструментов для ручного и автоматизированного тестирования и знакомство с BDD. Инструменты выбираются под технологический стек продукта, бюджет и квалификацию команды. Большинство средств автоматизации из этого модуля бесплатны и имеют открытый исходный код.

| 2 | Практика: лаборатория DevTools | Практика в браузере |

| 8 | Практика: подбор стека инструментов | Практика |
| 9 | Тест по модулю 6 | Тест |

**Результат модуля:** вы уверенно пользуетесь DevTools браузера, подберёте набор инструментов под конкретный проект, напишете автотесты для HTTP API и опишете сценарий на Gherkin.

В лаборатории DevTools учебный магазин прячет подсказки, которые можно найти только инструментами разработчика: во вкладках Elements, Console, Network, Application и в режиме устройства. Значения у каждого студента свои, ответы проверяет сервер.

В API-практиках работает демо-API интернет-магазина прямо в браузере. Сначала вы исследуете его вручную в API-консоли (упрощённый Postman), затем закрепляете проверки автотестами на JavaScript. Тесты должны поймать баги в версиях API с внесёнными ошибками.
