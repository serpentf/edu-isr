## Критерии оценки

| Критерий | Баллы |
|----------|-------|
| Инструменты соответствуют стеку проекта | 3 |
| Выбор обоснован с учётом команды, бюджета и нагрузки | 3 |
| Сценарии Gherkin корректны: Допустим / Когда / Тогда | 2 |
| Есть негативный сценарий | 2 |
| **Итого** | **10** |
