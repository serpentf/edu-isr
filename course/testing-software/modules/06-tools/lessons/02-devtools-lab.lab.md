# Практика: лаборатория DevTools

## Зачем тестировщику DevTools

**Инструменты разработчика** (DevTools) встроены в каждый современный браузер. Тестировщику они нужны каждый день:

- понять, **на чьей стороне ошибка**: если сервер вернул верные данные, а на странице они неверны, проблема во фронтенде, и наоборот;
- собрать **доказательства для баг-репорта**: текст ошибки из консоли, упавший запрос, код ответа (модуль 5);
- проверить то, чего не видно на экране: **скрытые элементы**, сохранённые данные, заголовки ответа;
- посмотреть **мобильную вёрстку** без телефона.

## Как открыть

| Браузер | Windows и Linux | macOS |
|---------|-----------------|-------|
| Chrome, Edge, Яндекс Браузер | F12 или Ctrl+Shift+I | Cmd+Option+I |
| Firefox | F12 или Ctrl+Shift+I | Cmd+Option+I |
| Safari | — | Cmd+Option+I (сначала включите «Меню Разработка» в настройках) |

Другой способ — щёлкнуть правой кнопкой по элементу страницы и выбрать **«Просмотреть код»** (Inspect).

## Вкладки, которые понадобятся

| Вкладка | Что показывает | Для чего тестировщику |
|---------|----------------|------------------------|
| **Elements** (в Firefox — Inspector) | HTML-разметку и стили страницы | Найти элемент, проверить текст и атрибуты, увидеть скрытое |
| **Console** | Сообщения и ошибки JavaScript | Текст ошибки для баг-репорта |
| **Network** | Все запросы страницы к серверу | Код статуса, тело ответа, заголовки; понять, чья ошибка |
| **Application** (в Firefox — Storage) | Cookies, Local Storage, Session Storage | Что сайт сохранил в браузере: токены, корзину, настройки |
| **Device toolbar** (значок телефона слева вверху) | Эмуляцию экрана телефона или планшета | Проверка мобильной вёрстки |

Важная привычка: **открывайте Network и Console до того, как воспроизводите ошибку**. Запросы, отправленные до открытия DevTools, во вкладку Network не попадают.

## Задание

Ниже — учебный магазин с намеренно спрятанными подсказками. Каждую из них можно найти только с помощью DevTools. Найдите их все и впишите ответы в форму под магазином.

Значения у каждого студента свои, поэтому подсмотреть ответы у соседа не получится. После проверки верные ответы подсвечиваются зелёным, а у неверных появляется подсказка, где искать.

**Порядок работы:**

1. Откройте DevTools и сразу вкладку **Network**.
2. Пройдитесь по магазину: нажмите кнопки, посмотрите на результат.
3. Ищите подсказки по вкладкам из таблицы выше. В форме у каждого вопроса указано, какая вкладка нужна.
4. Для последнего вопроса включите режим устройства и выберите ширину экрана меньше 576 px, например iPhone SE.

**Совет для баг-репорта.** Найденные здесь данные — ровно то, что разработчик хочет видеть в отчёте об ошибке: шаги, текст ошибки из консоли, код статуса и идентификатор запроса из Network.
