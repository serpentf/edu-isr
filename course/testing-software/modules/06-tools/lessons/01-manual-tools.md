# Инструменты ручного тестирования

## Цель урока

Узнать, какие инструменты помогают ручному тестировщику, и понять, что ручное тестирование не означает работу «голыми руками».

## Обзор

| Назначение | Инструменты |
|------------|-------------|
| Управление тест-кейсами | TestRail, Qase, Zephyr, qTest; Excel/Google Таблицы для малых проектов |
| Отслеживание дефектов | Jira, YouTrack, Redmine, Bugzilla |
| Скриншоты и запись экрана | Snagit, Lightshot, ShareX |
| Ручная проверка API | Postman, Insomnia |
| Анализ веб-страниц и трафика | Chrome DevTools, Charles, Fiddler |

## Зачем каждая группа

**Управление тест-кейсами (TMS).** Хранение тест-кейсов и чек-листов, планирование прогонов, отметка результатов, отчёты о покрытии. Для небольшого проекта хватит таблицы. Когда тест-кейсов становится сотни, без TMS трудно понять, что проверено в текущем релизе.

**Баг-трекеры.** Жизненный цикл дефекта из модуля 5 живёт именно здесь: статусы, назначение, комментарии, история.

**Скриншоты и запись экрана.** Скриншот со стрелкой или короткое видео часто объясняют дефект лучше абзаца текста. Это обязательные вложения хорошего баг-репорта.

**Ручная проверка API.** Postman и Insomnia позволяют отправить запрос к серверу без интерфейса. Так тестировщик понимает, на чьей стороне ошибка: если API возвращает верные данные, а на странице они неверны, проблема во фронтенде.

**DevTools и прокси.** Chrome DevTools показывают ошибки в консоли, сетевые запросы, позволяют эмулировать мобильное устройство и медленный интернет. Charles и Fiddler перехватывают и подменяют трафик, например чтобы проверить, как приложение ведёт себя при ответе сервера с ошибкой.

## Главное

- Ручной тестировщик использует TMS, баг-трекер, средства записи экрана, API-клиенты и DevTools.
- Postman и DevTools помогают локализовать ошибку: фронтенд или бэкенд.

## Вопросы для самопроверки

1. Когда для хранения тест-кейсов достаточно таблицы, а когда нужна TMS?
2. Как с помощью Postman определить, на чьей стороне ошибка — фронтенда или бэкенда?
3. Какие возможности DevTools пригодятся при проверке мобильной вёрстки?
